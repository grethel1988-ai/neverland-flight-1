# 永無島的初次飛翔：星空、仙塵與遺失的玩具

國小國語文**第一學習階段（低年級）**遊戲式線上測驗，採日系 RPG／視覺小說風格。

## 功能
- 封面前情提要（打字機效果）、強制輸入姓名
- 三種難度：見習飛行員（25題・3顆生命）／仙塵冒險家（40題）／永無島英雄（50題）
- 指標保證機制：每個學習表現（3-Ⅰ-1、3-Ⅰ-2、3-Ⅰ-3、4-Ⅰ-1、4-Ⅰ-2、4-Ⅰ-3、4-Ⅰ-5、5-Ⅰ-2、5-Ⅰ-3、5-Ⅰ-7、四字語詞）至少出現 1 題
- 四位夥伴（麥克、奇妙仙子、史萊特利、圖特斯），答對答錯都有符合人設的幽默回饋
- 題型：四選一、拖曳配對、拖曳填空、分類、排序／句子重組、短文閱讀（支援滑鼠與觸控，也可「點卡片→點框框」）
- 三關劇情：精靈山谷 → 樹屋派對 → 滴答沙灘，結局後顯示可列印證書（動態印上姓名與難度）
- 單一畫面不捲動、響應式設計

## 開發者快捷鍵（僅 localhost / file:// 有效）
| 鍵 | 功能 |
|---|---|
| F2 | 顯示本題答案 |
| F3 | 跳到下一關 |
| F4 | 直接到證書頁 |

## 本地執行
```powershell
python -m http.server 8000
```
開啟 http://localhost:8000

## 部署到 GitHub Pages
1. 將本資料夾推上 GitHub repository。
2. Settings → Pages → Branch 選 `main`、資料夾 `/ (root)`。
3. 所有路徑皆為相對路徑，已附 `.nojekyll`。

## 檔案
- `js/bank_mc.js`：選擇題（由兩份 docx 題庫轉出）
- `js/bank_drag.js`：拖拉題（依選擇題題庫素材改寫）
- `js/game.js`：遊戲流程
- `assets/img/`：壓縮後的角色與場景圖（webp）
